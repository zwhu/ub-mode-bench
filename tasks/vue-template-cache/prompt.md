Repeated compilation of a TypeScript single-file component can lose imports that are used only by its template. The problem appears when a template has already been compiled/transformed and the template analysis cache entry is later evicted, so a subsequent script compilation re-analyzes that descriptor. Fix this across the compilation pipeline. Preserve normal repeated compilation, template-only imports, v-model target handling, custom compilers and compiler options (including delimiters), SSR mode, and SFC-relative source locations. Existing diagnostics and ordinary untransformed templates must keep their behavior.
